- **muse: `/quit` with a running background task is handled deliberately instead of hanging on the quit menu (#1716).** With a backgrounded task running, muse answers `/quit` with a "Local work is still active" confirmation (`1. Exit anyway` / `2. Stay`) that no dialog matched, so stop/restart waited out the quit timeout and fell back to blind Ctrl-C. AgEnD now recognises the whole menu, holds deliveries while it is on screen (a stray Enter would pick "Exit anyway"), and the stop flow cancels it with Escape — never answering an option — before stopping the process itself, reusing the #1217 path. An idle auto-pause additionally defers while background work runs (see #1717) instead of silently killing it.
