- **Reply-completion guard fires correctly when kiro shows a dialog during a turn (#1839).** When kiro displayed a dialog (such as the Classic → V3 upgrade nudge) while processing a human message, the daemon's `applyInstanceStateSnapshot` returned early without calling `noteTurnActivity()`, leaving `busyObserved = false`. The guard's busy-observed gate then held the recovery prompt indefinitely — the user never received the "please reply" reminder. Activity is now recorded even when a dialog is blocking input, so the guard fires correctly once the dialog lifts and the turn ends without a reply.
